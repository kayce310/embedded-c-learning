
# Embedded C Learning

My personal learning repository for Embedded C and firmware development.

## Goals

- Learn C fundamentals and memory concepts.
- Practice debugging, testing, Git, and Makefile.
- Build reusable firmware-style modules.
- Learn MCU peripherals and RTOS after the fundamentals.
- Build a Mini Firmware Simulator as a portfolio project.

## Repository Structure

- `progress/`: learning logs and skill assessments.
- `01-c-basics/`: beginner C exercises.
- `09-git-practice/`: Git exercises and notes.

## Environment

- OS: Windows
- Editor: Visual Studio Code
- Language: C
- Git: version control

## Learning Rule

Every exercise should include code that I wrote, test results,
problems encountered, and a record of meaningful changes.
