
# Git Practice

## Exercise 1: First Commit

- [ ] Create a learning log.
- [ ] Check changed files with `git status`.
- [ ] Inspect changes with `git diff`.
- [ ] Stage only the intended files.
- [ ] Inspect staged changes.
- [ ] Create a commit.
- [ ] Push the commit to GitHub.

## Exercise 2: Track Changes

- [ ] Modify one file.
- [ ] Inspect the diff.
- [ ] Commit the change.
- [ ] Find the commit in `git log --oneline`.

## Exercise 3: Branch Practice

- [ ] Create a feature branch.
- [ ] Make a small change.
- [ ] Commit and merge it into `develop`.
